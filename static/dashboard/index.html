What "revenue recovered" means here

The batch tab reports the completed 50-case run: a real diagnosis → strategy → agent → policy-gate pipeline ran for every case, but no live customer clicked a link in that run, so it measures recovery-attempt rate, not rupees actually recovered. The live tab is different: every case there was created by an actual person (you, a judge) clicking through the chat UI just now - the agent's decisions, the gate's rejections, and the discount it offered are all real actions taken this session, gated exactly as they would be in production.
